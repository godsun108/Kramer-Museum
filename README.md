# Kramer Museum

A living museum of life, ideas, creativity, Earth restoration, and exploration.

## The experience

Kramer Museum is an independent, evolving public collection. It is designed as a set of rooms and exhibits rather than a conventional profile page.

The first edition includes:
- The Music Room: instruments, production, DJing, and five-rhythm dance journeys
- Books & Questions: a personal reading shelf
- Field Notes: outdoor life, sport, and places remembered
- Zeke & the Van: a story exhibit
- Stories Still Unfolding: travel, ventures, and conservation connections
- Community & Service: editable placeholders for church, foundation, and nonprofit
- Earth Restoration & Emergency Response: the mission and intended operating model
- A Regenerative Ecosystem: long-range ambitions, clearly distinguished from current operations

## Publishing

This is a static site. To publish with GitHub Pages:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. GitHub Pages will provide the public site URL after deployment completes.

## Editorial principles

- Publish only personal details the subject chooses to share.
- Do not invent biography, affiliations, roles, partnerships, or accomplishments.
- Clearly distinguish personal recollection, aspirations, and verified operational activity.
- Keep organization names as placeholders until confirmed.
- Add photographs and fuller stories with permission and context.

## Development

The site currently uses a single self-contained `index.html` with responsive styling and no build step or third-party JavaScript dependencies.
